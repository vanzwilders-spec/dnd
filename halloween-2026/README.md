# The Reveler's Stage (Halloween 2026)

Six players, levels 3 to 7 over four Friday sessions (Oct 16, 23, 30, Nov 6; Nov 13 is the spare). Markdown is the master; the HTML files are generated from it with `_shared/build_html.py`.

- `dm/` : everything for the DM (script, stat blocks, hazards, run sheet, roster, decisions log)
- `players/` : player-facing handouts and the Player Guide
- `maps/` : PNGs for AboveVTT (see `maps/LINKS.md`)

**Start here:** `dm/Decisions_Log.md`, then `dm/Session1_RunSheet.md`.
